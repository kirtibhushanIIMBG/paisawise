# Bank and UPI logos

The "Reads every account and UPI app you already use" ribbon on the home page
renders a real logo for any brand whose file is present here, and falls back to
a typeset wordmark for the rest. Adding one is a file drop — no code change.

## Filenames

Name the file after the brand key, in `.svg` (preferred), `.webp`, `.png` or
`.jpg`. The first extension found wins.

| File | Brand |
| --- | --- |
| `hdfc.svg` | HDFC Bank |
| `icici.svg` | ICICI |
| `gpay.svg` | Google Pay |
| `phonepe.svg` | PhonePe |
| `axis.svg` | Axis Bank |
| `paytm.svg` | Paytm |
| `sbi.svg` | SBI |
| `kotak.svg` | Kotak |

## What to supply

Use each brand's own press/media-kit asset. Prefer a **monochrome or
single-colour** version: the ribbon renders them at ~28px tall in a row, and
eight full-colour logos next to each other fight both one another and the gold
accent.

## Before you ship this publicly

These are third-party trademarks, and a logo row on a product page normally
reads as "we are integrated with these". PaisaWise is a fictional academic
project, so no such integration exists. For coursework that is understood;
if this ever went live it would need either real agreements or a caption
making the illustrative status explicit.
